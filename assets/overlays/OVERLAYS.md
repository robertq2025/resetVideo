## 2. 统一贴合规则

1. **先空后贴**：生成 prompt 里写“屏幕为深色空白面板，无文字；纸面空白，无字迹”，避免模型生成乱码。
2. **四角定位**：用四边形变形（corner pin）贴合屏幕/纸面四角，不要只用旋转。
3. **匹配镜头**：贴图后统一加原片的高斯模糊量（S11/S21 浅景深 → 2–3px；大全景 → 0.8px）。
4. **匹配光**：屏幕类用 Screen / Add 混合，纸面类用 Multiply 压暗 + 原片颗粒。
5. **匹配颗粒**：贴图之上重铺同强度胶片颗粒（`08_剪辑交付.md` 的颗粒层），否则文字会“浮”在画面上。
6. **可读性优先于真实感**：0.5 秒内读不到关键信息（04:17 / 09:00 / 047）就放大或延长该镜头。
7. 已经生成的 11 个镜头里，**S14 公交车牌、S32 桌面纸页**含模型乱码文字：按第 5 节处理（S32 已落地为采用条，S14 待逐帧跟踪）。

## 3. 生成 prompt 的统一附加句

图像/视频 prompt 末尾统一加：

```text
屏幕与纸面保持空白无文字，不要生成任何可读字符、logo、水印；文字后期合成。
keep all screens and paper surfaces blank and unlettered; do not render any readable text, logo or watermark; typography is composited in post
```

负面词补充：`乱码文字, 伪汉字, 可读招牌, 字幕, 水印, gibberish text, fake chinese characters, readable signage, subtitles, watermark`
