# 《重启》逐镜生成包 / HANDOFF KITS

每镜四件套：`Sxx_frame.png`（首帧，本地已统一为 1920×1080）· `Sxx_card.png`（一页视觉简报）· `Sxx.json`（全字段）· `Sxx_prompt.txt`（图像/视频提示词 + 负面词 + 不变项 + 是否需要落幅帧，可直接粘贴）。

有对白的 32 镜各附一条 `Sxx_vo.wav`（48kHz 立体声，句内时间与主片一致），口型策略写在 `Sxx.json.lipsync.policy` 与提示词的“口型”块：默认不做唇形，只有 S21/S22 这类正脸关键镜头做；唇形一崩就回退画外。

需要落幅帧的 13 镜里，**9 镜的 `Sxx_end.png` 已随包**（成片末帧、同 clip 另一裁切或真实贴图底板派生，来源记在 `exports/REBOOT_end_frames.csv`）；S15 / S22 / S30 / S42 的落幅需要新内容，仍待图像额度。

整个 `handoff/` 目录可单独交付给外部视频工具：不需要再回查分镜表、提示词包或连续性锁。

`OVERLAY/` 共 14 张真实文字贴图。画面里的字一律不由模型生成：生成时留空，生成后按每镜 `Sxx.json.text_overlays`（也写在 `Sxx_prompt.txt` 的“生成后贴图”块）贴对应图。贴合规则：先空后贴：生成时屏幕/纸面留空，无可读字符；四角定位（corner pin）贴合屏体或纸面，不要只用旋转；匹配镜头虚化：浅景深镜头 2–3px，大全景 0.8px；屏幕类用 Screen/Add 混合；纸面类用 Multiply 压暗后重铺原片颗粒；贴图之上必须重铺同强度胶片颗粒，否则文字会浮在画面上；可读性优先：0.5 秒内读不到 04:17 / 09:00 / 047 就放大或延长该镜

`REF/` 共 26 张锁定参考图（定妆图 / 角色页 / 成片脸部基准 / 10 场景卡 / 7 道具卡 / AI 角标），每镜用哪几张写在该镜的 `Sxx.json.reference_images` 与 `Sxx_prompt.txt` 的“参考图”块。

统一规格：1920×1080 / 24fps / 16:9；屏幕与纸面**不得由模型生成文字**（贴图见 `assets/overlays/`）；全片左下常驻 AI 角标 `assets/overlays/AI_badge.png`。
